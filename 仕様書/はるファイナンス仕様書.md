## これは何か（What）

**はるファイナンス**は、はるが **1 人で使う個人向けの家計簿アプリ**。
カップル共有アプリ「たくはるファイナンス」をベースに複製し、共有のための機能を
すべて外して個人用に作り直したもの。配色は**水色ベース**。

- パッケージ: `com.haru.finance`（表示名「はるファイナンス」）
- 内部名（Flutter package）: `haru_finance`（namespace は `com.takuharu.finance` のまま流用）
- 置き場所: `C:\dev\CompanyOps\Application\finance-apps\apps\haru_finance`（melos モノレポ内の 3 つ目のアプリ）
- 配信: **Android のみ**（GitHub Release 経由の OTA 自動更新）

## たくはるファイナンスからの差分（削除した「共用機能」）

個人アプリなので、二人で使う前提の機能はすべて削除した。

| 削除した機能 | 内容 |
|---|---|
| 世帯共有（household） | `households/TAKUHARU` の固定共有世帯。→ すべて `users/{uid}` 配下の本人データに変更 |
| メンバー管理 | メンバー名/アイコン編集、世帯コード参加 |
| 割り勘・精算 | わりかんカード |
| 支払者（paidBy） | 「だれが払った？」セレクタ、明細の 💳 支払者表示 |
| 個人の食費わく | personalFor / 個人食費予算 |
| プランニング | やりたいこと/行きたい場所/お店の共有リスト |
| チャット・コメント | 取引・レシート・プラン項目ごとの会話（相手との会話） |
| 相手への通知 | FCM プッシュ・相手の登録のまとめ通知・通知受け取り設定タブ |

## データ構造（Firebase: takuharu-finance を流用）

はるの個人データは、たくはると同じ Firebase プロジェクト `takuharu-finance` の
**`users/{uid}` 配下**に、本人だけのものとして保存する（共有世帯 `households/**` には
一切触れない）。

```
users/{uid}                    { name, paymentMethods[], replacements[],
                                 customExpenseCats[], customIncomeCats[], monthlyBudget }
users/{uid}/transactions/{id}  収支の取引
users/{uid}/subscriptions/{id} 固定費・サブスク
users/{uid}/accounts/{id}      口座・クレカ・現金（残高）
```

- スコープ管理: `HouseholdService`（名前は互換のため据え置き。`householdId` ゲッターは
  ログイン中の uid を返す）。各リポジトリの保存先は `users/{uid}/…`。
- 共通モデルは `packages/finance_core`（FutaFinance/たくはると共有。改変しない）。
  `Transaction` の `paidBy` / `personalFor` / `recordedBy` / `commentCount` フィールドは
  モデルに残るが、はるでは書き込まない（無害）。

### Firestore セキュリティルール

`firebase/takuharu/firestore.rules` に以下を追加済み（要・本番反映）:

```
match /users/{uid} {
  allow read, write: if isSignedIn() && request.auth.uid == uid;
  match /{document=**} {
    allow read, write: if isSignedIn() && request.auth.uid == uid;
  }
}
```

- `users/{uid}` サブツリーは**許可リスト(allowedUsers)不要＝ログイン中の本人のみ**。
  → はるがどの Google アカウントでログインしても、自分のデータにだけアクセスできる。
- 共有データ `households/**` は従来どおり `allowedUsers` で保護したまま（たくはるへ影響なし）。

## 画面・機能

下部ナビ 5 タブ（ホーム / 支出 / 収入 / 資産 / 分析）＋設定（お金・データ・アプリの 3 タブ）。

- **ホーム**: 月切替、今月の収支サマリー（水色グラデ）、今月の予算（進捗・使いすぎ警告）、
  支出の内訳（カテゴリ別・タップで明細展開）、最近の入出金。FAB「きろく」。
  明細タップ＝編集画面（旧チャットは廃止）。
- **支出 / 収入**: 月切替・合計・カテゴリ内訳・一覧（検索/並び替え）。レシートまとめ表示。
- **資産**: **ためた合計**（記録開始からの 収入−支出。口座があればその初期残高も加算）を
  大きく出し、下に選んだ月の「増えた分」＋入金/出金＋その月の明細（v1.0.7〜）。
  口座を登録している場合だけ、さらに下に口座ごとの残高カードが並ぶ。口座の残高は
  「口座名＝取引の支払元」が一致する取引を積み上げて出すので、口座を使うなら
  口座名と支払方法の名前をそろえる（v1.0.6 で支払元は口座名ではなく支払方法になった）。
- **分析**: 上部の「月で見る／年で見る」で切替（v1.0.6〜）。
  - 月で見る: 6 ヶ月の収支推移＋当月カテゴリ内訳（円グラフ・エンゲル係数・カテゴリ別）。
  - 年で見る: 年の切替バー、その年に貯まった分＋1年の収入/支出、記録開始からの累計
    （ためた合計＝収入−支出）、12 ヶ月の収支グラフ、その年のカテゴリ内訳。
- **記録**: 手入力（金額・日付・品名・カテゴリ・支払元・画像添付）／レシート読み取り
  （Gemini OCR・品目内訳・まとめ or 品目ごと記録）。支払元は**設定の支払方法**から選ぶ
  （既定は「クレカ」「現金」の 2 つ・設定 > お金 で増減できる／未選択では保存できない）。
  昔の記録が今は無い支払元で保存されている場合は、その値も選択肢の末尾に出して
  選択が外れないようにする。
- **画像の添付（レシート・給与明細）**: 本人のドライブのマイドライブ直下「はるファイナンス」
  → `YYYY年/MM月` に非公開で保存する（スコープは `drive.file`＝このアプリが作った物だけ）。
  保存ボタンはアップロードの完了を待ってから記録を書き込む（待たずに保存すると画像が
  どの記録にも紐づかず迷子になるため）。失敗したときは理由を出して「もう一度ためす」か
  「画像なしで保存」を選べる。収入一覧にはバッジが出て、タップで明細を直接開ける。
- **固定費・サブスク**: 毎月/毎年、支払日、今月分を支出に記録（二重防止）。
- **設定 > データ**: 貼り付け取り込み（TSV）、変換マスタ（表記ゆれ辞書）、
  消費税・差額カテゴリの一括直し。
- **自動更新（OTA）**: 起動時＋復帰時に `release/haru-version.json` を確認し、新版 APK を
  DL してインストール。

## デザイン

- 配色は水色ベース。`AppColors` のフィールド名（`pink` / `pinkDark` / `pinkSoft`）は
  たくはる由来のまま残しているが、**値はすべて明るい水色系**（`pink`=#4FC4F0 /
  `pinkDark`=#1E9FD9 / `pinkSoft`=#DDF3FD / `bg`=#F2FBFF）。支出=コーラル #F4796B、収入=ミント #35C2A0。
- v1.0.4 で、たくはる複製時に各画面へベタ書きで残っていたピンク（総額カードのグラデ
  #FF6B8A 系・ログイン背景・円グラフの淡ピンク等）を水色グラデ #6FD0F5→#1E9FD9／淡水色に
  差し替え、たくはるファイナンス（ピンク基調）との被りを解消。支出の総額カードのみ支出色の
  コーラル #F4796B グラデ。カテゴリ別の色分けは機能上の多色パレットとして据え置き。
- フォント: Zen Maru Gothic（丸ゴシック）。
- アイコン/ロゴ: 白いコイン＋¥＋キラッ、明るい水色グラデ（`assets/icon/`・`assets/brand/logo.png`）。

### 広い画面（Web/タブレット）の中央寄せ（v1.0.8〜）

はるファイナンスはスマホ前提で作ってあるため、パソコンのブラウザや大きめのタブレットで
開くと一覧も入力欄も画面幅いっぱいに引き伸ばされて読みにくかった。たくはるファイナンス
v0.2.114 と同じ考え方を横展開してある。**狭い画面（スマホ）の見え方は一切変わらない。**

- `lib/widgets/web_layout.dart` に `WebCenterFill` と `WebEndFloatFabLocation` を新設。
  - `WebCenterFill` は**横幅だけ**を抑えて中央に置く（高さは画面いっぱいのまま保つ）。
    高さを緩める作りにすると `Column`＋`Expanded` や設定画面の「左レール＋右内容」が崩れるため。
  - `WebEndFloatFabLocation` は FAB を画面右端ではなく**本文の右端**に置く。
    `ScaffoldPrelayoutGeometry.scaffoldSize` から余白を計算する。
- 全16画面の `body` を `WebCenterFill` で包む。最大幅は中身で使い分け：
  **一覧・グラフ系＝1040 ／ 設定＝900 ／ フォーム・レシート系＝720。**
- ボトムシート（4箇所）は最大幅560、記録メニューのダイアログは420、
  ログイン画面のボタン群は380。いずれも既定では横いっぱいに広がるため個別に抑える。
- 全画面フルブリードのまま残したもの：ログインの背景グラデーション／レシート撮影／レシート画像ビューア。
- ⚠ はるファイナンスは**Android配布のみでWeb公開はしていない**ので、この対応が効くのは
  大きめのタブレット・折りたたみ端末と、開発時の `flutter build web` での確認時。

## バージョン管理・配信

- `apps/haru_finance/pubspec.yaml` の `version: X.Y.Z+B` を改修毎に +1。
- Android: `flutter build apk` → `gh release create haru-vX.Y.Z`（repo `fffuttta-design/finance-apps`）
  → `release/haru-version.json` 更新 → `git push`。OTA が検知して自動更新。
- 署名: `android/app/takuharu-release.jks`（alias `takuharu`）を流用。
  SHA-1 = `3C:53:51:C3:26:1E:B1:96:1D:F1:68:EC:45:8E:5D:86:0C:1A:87:3D`。
